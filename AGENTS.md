# AGENTS.md

This is the **source repo** for `novel-harness`, a Bun CLI that scaffolds and
validates OKF v0.2 novel bundles and renders coding-agent adapters. You are
editing the tool, not a novel: don't confuse this repo with the `story/`
bundles it generates (see `sandbox/`, `tests/fixtures/`).

## Verification

```bash
bun test            # 256 tests, bun:test, ~18s
bun run typecheck   # tsc --noEmit, strict
```

- `bun run lint` is an alias for `typecheck`; there is no separate linter.
- Always run `typecheck` and `test` after changes. `tsconfig.json` includes
  `tests/`, so test files are typechecked too.
- Run a single file: `bun test tests/query.test.ts`.

## Runtime & style

- **Bun only** (>= 1.1). No Node/npm; `bun install` uses `bun.lock`.
- Relative imports use explicit `.ts` extensions (e.g.
  `../../core/bundle/bundle.ts`); `allowImportingTsExtensions` + bundler
  resolution. Keep that style.
- `verbatimModuleSyntax` is on: type-only imports must use `import type`.
- `noUncheckedIndexedAccess` is on: array/record indexing yields
  `T | undefined` — guard before use.

## Architecture

- CLI entrypoint `bin/novel.ts` -> `src/cli/main.ts`. One file per subcommand
  in `src/cli/commands/` (thin arg parsing + `openProject`), all logic in
  `src/core/**`. Library entry: `src/index.ts`.
- `src/core/adapters/` render agent artifacts (AGENTS.md, CLAUDE.md,
  `.opencode/`, `.claude/`, `.gemini/`). Generated files carry a
  "generated by novel-harness — do not edit; run `novel sync`" header.
- Design constraints (see `docs/SPEC.md`, decisions log at its end): the CLI
  **never calls an LLM**; no MCP; OKF v0.2 conformance is a hard requirement;
  **original novels and series are the primary focus**. Fanfiction is fully
  supported (`origin`, `diverges_at`, `canon_type`) but is a secondary mode.

## Testing gotchas

- `tests/golden/` holds exact-match snapshots of adapter output and validator
  messages (`tests/golden.test.ts`). Changing what adapters/validator render
  requires manually updating those files — there is no updater script. The
  `tests/golden/AGENTS.md` is a generated *fixture*, not repo instructions.
- Fixture bundles live in `tests/fixtures/valid-story/`. Unit tests mostly
  build throwaway bundles in a temp dir via `makeBundle` in
  `tests/helpers.ts`.

## Sandbox / end-to-end

- `bash scripts/sandbox.sh [preset]` rebuilds the gitignored
  `sandbox/<preset>/` playground (presets: `teenwolf` default, `sherlock`,
  `blank`, `harrypotter`, `naruto`, `supernatural`, `twilight`). Each preset
  gets its own folder, so they coexist.
- The script warns (and agents should too) when `novel` is not on PATH; run
  `bun link` in the repo root to expose it.
- Try a preset end to end: `cd sandbox/teenwolf && opencode`.
